# 성적 뒤에 숨은 이야기, 데이터를 통해 읽다
-----

## 교육분야 : 학생 성적 요인 분석 프로젝트
-----

멋쟁이 사자처럼 데이터 분석 4기 미드 프로젝트 4팀
> 이 프로젝트는 kaggle 내의 르투갈의 두 개 고등학교 학생들을 대상으로 수집된 **공개 CSV 데이터셋**을 활용해 학생들의 시험 점수(성적)와 함께 인구통계, 가정 환경, 학교 생활 등의 데이터를 수집하고,
> 이를 바탕으로 **최종 성적에 미치는 영향**을 분석하여 의미 있는 인사이트를 도출하는 것을 목표로 합니다.
